# AMO TECH website

Advanced Modern Operations  
Innovating Today. Transforming Tomorrow.

## Open the website

Open `index.html` in a modern browser. Keep `styles.css`, `app.js` and the `assets` folder beside it. No installation or build is required. Fonts load from Google Fonts when available; local fallback fonts work offline.

## Included

- Responsive desktop and mobile layouts using the supplied logo.
- Services, company introduction, team approach, delivery process and technology sections.
- Filterable illustrative project concepts and accessible detail dialogs.
- Frequently asked questions and privacy information.
- Quotation brief form with required-field validation and a downloadable text brief.
- Mobile menu, keyboard focus indicators and reduced-motion support.

## Quotation form

The form creates a downloadable brief on the visitor's device. It does not send email or save enquiries on a server. The interface states this explicitly. Connect an approved form endpoint and confirmed business mailbox before accepting online enquiries; update the privacy notice to match.

## Editing and hosting

Edit content in `index.html`, design in `styles.css` and interactions in `app.js`. Upload the contents of this folder to a static web host with HTTPS. The logo is stored locally in `assets/amo-tech-logo.png`.
